# 독도 원정대

독도의 날(10월 25일) 계기교육용 초등학생 대상 3D 웹 게임 프로토타입입니다.

- 울릉도에서 독도까지 87.4km 새벽 항해 (방향키·스페이스바 또는 터치 버튼)
- 탐사선 '독도탐험호'를 몰고 항해 (조타실, 레이더, 구명환, 난간, 뱃머리의 탐험대원)
- 바다에 떠 있는 유리병 기록 12개(퀴즈 포함)
  - 역사: 512년 이사부, 1454년 『세종실록』「지리지」, 1696년 안용복, 1877년 태정관 지령, 1900년 칙령 제41호, 1953년 독도의용수비대
  - 자연: 동도·서도와 89개 바위섬, 화산섬의 탄생, 괭이갈매기, 조경수역과 독도새우, 해국·사철나무, 강치
- 항해 중반 풍랑 이벤트: 비·번개·높은 파도 속에서 옆에서 오는 큰 파도를 뱃머리로 받아 넘기고, 풍랑주의보와 독도 입도가 어려운 까닭을 배우는 날씨 노트
- 독도 3D 탐사 8곳: 독도경비대, 독도 등대, 천장굴, 독립문바위, 주민 숙소, 물골, 괭이갈매기 번식지, 가제바위
- 바닷속 잠수 탐사: 독도 둘레 바닷속 길을 헤엄치며 바다 숲(감태·대황), 독도새우, 전복, 해삼, 혹돔, 성게와 갯녹음을 찾아 관찰 노트를 모으고, 마지막에 사라진 강치를 기억하는 장면
- 마지막 관문: 유튜브 영상 시청(출처 표기) 후 독도 지킴이 임명장

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다. three.js는 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

```sh
npx serve .   # 또는 python3 -m http.server
```

GitHub Pages에서 저장소 루트를 배포하면 바로 열 수 있습니다.

## 사진·영상

- 기록 카드와 탐사 설명에 실제 사진이 함께 나옵니다. 사진은 `assets/photos/`에 있고, 출처와 라이선스는 [CREDITS.md](CREDITS.md)와 게임 안 '사진·영상 출처' 화면에 있습니다.
- 마지막 관문 영상은 `index.html`의 `VIDEO` 설정(영상 ID, 제목, 채널)으로 바꿀 수 있습니다.
- 사진을 더 넣으려면 `PHOTOS` 목록에 `{ src, alt, credit, link }`를 추가합니다. 저작권이 확인된 사진만 넣어 주세요.
