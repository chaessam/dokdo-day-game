# 독도 원정대

독도의 날(10월 25일) 계기교육용 초등학생 대상 3D 웹 게임 프로토타입입니다.

- 울릉도에서 독도까지 87.4km 새벽 항해 (방향키·스페이스바 또는 터치 버튼)
- 바다에 떠 있는 유리병 기록 5개: 512년 이사부 → 1454년 『세종실록』「지리지」 → 1696년 안용복 → 1900년 칙령 제41호 → 1953년 독도의용수비대, 각 기록마다 퀴즈
- 독도 3D 탐사 6곳: 독도경비대, 독도 등대, 독립문바위, 주민 숙소, 물골, 가제바위
- 탐사를 마치면 독도 지킴이 임명장

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다. three.js는 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.

```sh
npx serve .   # 또는 python3 -m http.server
```

GitHub Pages에서 저장소 루트를 배포하면 바로 열 수 있습니다.
